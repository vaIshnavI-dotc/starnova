# Data statement

## Data categories
- **Collected/real data:** document the origin, collection date, licensing/terms, and any transformations for each source.
- **Synthetic data:** generated examples used for testing. Clearly label them and never present them as real observations.

## Privacy and source handling
- Store source identifiers in anonymised form where possible.
- Record whether a source is SEBI-registered and the provenance (`data_origin`) where known.
- Remove personal information before analysis and publication.
